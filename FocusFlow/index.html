FAQ

Questions Before You Install

What browsers are supported?

FocusFlow supports Chrome, Firefox, Microsoft Edge, Brave, and Opera.

Does FocusFlow work offline?

Yes. Core task planning and organization features are designed to work locally in your browser.

Is my data private?

FocusFlow is local-first, has no ads, does not sell data, and does not track by default.

Can I export my tasks?

Yes. Export and backup options are available so you can keep your planning data portable.

Is there a free version?

FocusFlow includes a free version for core planning, focus, and organization workflows.

How is FocusFlow different?

FocusFlow is a focus-first browser productivity extension built for low cognitive load, fast capture, simple routines, accessibility, and local-first task management.
